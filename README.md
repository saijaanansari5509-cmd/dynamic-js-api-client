# Dynamic Data Explorer

A responsive web application that fetches live data from a REST API and lets users search, filter, sort, and explore posts.

## Features
- Fetch posts using REST API
- Search posts by title and description
- Filter posts by category
- Sort titles A–Z and Z–A
- Load more posts dynamically
- Loading and error handling with retry option
- Responsive desktop and mobile layout

## Technologies
- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- JSONPlaceholder REST API
